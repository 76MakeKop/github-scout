# GitHub Scout

**Сфера:** вход для человека — что это, как поставить, как запустить, что получишь.
**Обновлено:** 2026-09-03.

## Что это

Инструмент командной строки: описываешь задачу обычными словами — получаешь пять
репозиториев с вердиктом **USE / FORK / BUILD**, лицензионным паспортом и аргументацией
по каждому. Scout не клонирует репозитории и не запускает чужой код: он работает только
через GitHub REST API — метаданные, README, дерево файлов, манифесты зависимостей.
Отвечает он не на вопрос «что тут популярного», а на вопрос «брать готовое, дорабатывать
форк или писать своё».

## Как работает

```
NL-запрос → интент (синонимы, гипотезы имён библиотек)
          → 5–10 разных GitHub-запросов
          → поиск, дедуп, переранжирование RRF → топ-50
          → Слой 1: скрининг дешёвой моделью → топ-10
          → Слой 2: аудит дорогой моделью → топ-5 → отчёт
```

Смысл каскада — платить дорогой моделью только за финалистов. Один скан обходится
примерно в 0,13 $ в off-peak против 0,545 $, если гнать всех кандидатов через одну
крупную модель.

Как из задачи получаются поисковые запросы — `QUERIES.md`. Границы слоёв, кэш,
токеномика — `ARCHITECTURE.md`.

## Установка

Нужен Python 3.11+.

```bash
git clone <repo> && cd scout
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pre-commit install
```

Переменные окружения:

| Переменная | Обязательна | Зачем |
|---|---|---|
| `DEEPSEEK_API_KEY` | да | интент, Слой 1, Слой 2 |
| `GITHUB_TOKEN` | да | без токена лимит поиска 10 запросов/мин вместо 30 |
| `QWEN_API_KEY` | нет | fallback Слоя 2, если DeepSeek отдаёт 5xx |

Токену GitHub достаточно прав на чтение публичных репозиториев — `public_repo`
для classic-токена, `Public repositories (read-only)` для fine-grained.

```bash
cp .env.example .env    # затем вписать ключи
```

## Команды

```bash
# основной сценарий
python -m scout scan "нужен парсер PDF-таблиц на Python"

# сузить или расширить
python -m scout scan "..." --max-candidates 50 --audit-limit 10 --report-limit 5

# отложить до ближайшего off-peak окна (дешевле вдвое, но не сразу)
python -m scout scan "..." --off-peak

# игнорировать кэш аудитов для этого запуска
python -m scout scan "..." --refresh

# кэш
python -m scout cache list
python -m scout cache drop <repo_id>

# качество: прогон golden-set, метрика recall@5
python -m scout eval --golden tests/golden/
```

По умолчанию запуск синхронный и укладывается в 5 минут независимо от времени суток.
`--off-peak` ставит задачу в очередь: дешевле, но ждать до 12 часов.

## Пример отчёта

Фрагмент вывода — один кандидат из пяти:

```markdown
## 1. camelot-dev/camelot — USE  (оценка 0.81)

Извлекает таблицы из текстовых PDF в DataFrame, сохраняя строки и столбцы.
Покрывает задачу целиком; OCR для сканов не делает — но этого и не требовалось.

**Сильные стороны**
- Два режима разбора (lattice / stream) — работает и с разлинованными, и с чистыми таблицами
- Есть тесты и CI, релизы выходят регулярно
- Прямой экспорт в CSV и pandas.DataFrame

**Слабые стороны**
- Тянет opencv-python — тяжёлая нативная сборка
- Сканы без текстового слоя не поддерживаются

**Лицензия**  MIT · copyleft: нет · переиспользование кода: разрешено
Обязательства: сохранить текст лицензии и copyright.
Определено по файлу LICENSE (commit a1b2c3d, 2026-09-03).

**Трудозатраты на интеграцию**  2 / 5 / 10 дней (низ / вероятно / верх)

**Источники**  README.md · pyproject.toml · LICENSE · дерево файлов @ a1b2c3d
```

Машинный источник истины — JSON по схеме `Report` из `SCHEMAS.md`. Markdown выше —
его рендер для чтения человеком.

## Карта документации

| Файл | Зачем читать |
|---|---|
| `README.md` | ты здесь: поставить и запустить |
| `CLAUDE.md` | контракт с LLM-агентом: запреты, лимиты, целевые показатели, где живут промпты |
| `ARCHITECTURE.md` | границы слоёв, кэш, разделение контекстов, токеномика, обработка ошибок |
| `SCHEMAS.md` | JSON-контракты всех стыков конвейера — при правке любого слоя |
| `QUERIES.md` | семь семейств запросов и формула переранжирования — при работе над качеством поиска |
| `ROADMAP.md` | план на 3 недели, golden-set, методика recall@5, что отложено и почему |
| `CHECKLIST.md` | ручная проверка перед merge |
| `decisions_log.md` | почему сделано так, а не иначе, и что уже отвергнуто |

Полный список запретов для агента — в `CLAUDE.md`, здесь он не дублируется.
